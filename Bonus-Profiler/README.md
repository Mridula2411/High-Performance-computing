# My Profiler

A modular CPU, GPU, and Memory profiler for Python applications.

## Installation for development

Install the package in editable mode from the project directory:

```bash
pip install --no-build-isolation --user -e ./Bonus-Profiler
```

Or from within the Bonus-Profiler directory:

```bash
pip install --no-build-isolation --user -e .
```

## Requirements

- Python >= 3.10
- psutil
- plotly
- tabulate
- ipywidgets
